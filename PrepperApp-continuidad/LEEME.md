# Continuar PrepperApp en Codex

1. Extraé esta carpeta dentro de `/home/seba/AndroidStudioProjects/PrepperApp`.
2. Abrí el proyecto en Codex con acceso a sus archivos.
3. Indicá: **«Leé PrepperApp-continuidad/CONTINUIDAD.md y la demo HTML de esa carpeta. Continuá la implementación sobre este proyecto siguiendo ese contexto.»**

- `CONTINUIDAD.md`: objetivos, cuatro pantallas, reglas de negocio, modelo propuesto, recordatorios, límites de Android y etapas de implementación.

No reemplaces archivos del proyecto con esta carpeta: es documentación de referencia adicional.
